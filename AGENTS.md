# Photochem — Project Guide

## Назначение

iOS-приложение для проявки фотоплёнки: журнал комплектов химии, расчёт времён этапов с учётом пробега и таймер сеанса. Один сеанс последовательно проводит несколько плёнок через этапы выбранного процесса.

## Стек

- Swift, iOS 18+, SwiftUI, Observation.
- SwiftData — комплекты химии, сессии, плёнки и снимки этапов.
- Swinject, SwinjectAutoregistration и JustKitDI — сборка зависимостей.
- ActivityKit и WidgetKit — Live Activity и виджеты.
- Swift Testing, SwiftLint.

## Структура

- `Photochem/Photochem.xcworkspace` — workspace приложения и локального пакета ядра. Открывать его, чтобы видеть оба набора тестов.
- `Photochem/Photochem/` — приложение: `Model/`, `Service/`, `DI/` и `View/`.
- `Photochem/PhotochemCore/` — Swift-пакет расчёта времён и валидации конфигурации, с собственными тестами.
- `Photochem/PhotochemTests/` — тесты приложения, сервисов и раннера.
- `Photochem/PhotochemWidgets/` — расширение виджетов.
- `config/` — JSON-файлы процессов; `index.json` генерируется при сборке, вручную его не менять.

## Архитектура и правила данных

Расчёт и валидация конфигурации находятся в PhotochemCore; сохраняй независимость ядра от SwiftUI и SwiftData. В приложении модели хранят данные, сервисы выполняют операции, ViewModel управляют состоянием экранов. Регистрации зависимостей находятся в `DI/` и сборках соответствующих экранов; следуй существующим соглашениям Swinject и JustKitDI.

- Пробег комплекта вычисляется по всем плёнкам всех сессий, включая прерванные; отдельным счётчиком его не хранить.
- Времена этапов фиксируются при старте сессии в `StageSnapshot`. `SessionRunner` использует этот снимок; обновление конфигурации не должно менять уже начатую сессию или её историю.
- Раннер работает по абсолютному времени окончания этапа. Паузы нет; финальный сигнал заканчивается сам, затем начинается подготовка следующего этапа.
- Новый конфиг применяется только после валидации; некорректный ответ сервера не должен затирать рабочие данные.

## Проверки

Тесты ядра:

```sh
swift test --package-path Photochem/PhotochemCore
```

Схема `Photochem` использует `Photochem/Photochem.xctestplan`: в нём тесты приложения и PhotochemCore. Для запуска через Xcode используй workspace и эту схему. В CI проверки запускают workflows из `.github/workflows/` через RepoKit.

Свой конфиг линтера — `Photochem/.swiftlint.yml`, он наследует базовый. Проектные исключения и правила добавляй в свой конфиг.

## Git

Semantic commits на английском: `feat:`, `fix:`, `refactor:`, `chore:`, `test:`, `docs:` и другие Conventional Commits по смыслу изменения. Изменения — в ветках задач; в `master` они попадают через PR. Не изменять версии и release-теги вручную: ими управляет release workflow.

ConvenienTimer — отдельный старый проект-референс. Не менять его в рамках работы над Photochem.
