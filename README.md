# Photochem

Photochem — умный таймер для проявки плёнки на iPhone. Рассчитывает длительность этапов, ведёт отсчёт и подаёт звуковые сигналы.

## Зачем отдельный таймер

Во время проявки нужно следить за временем текущего этапа и готовиться к следующему. Перед началом — определить длительность каждого этапа с учётом процесса, количества плёнок в бачке и пробега химии. С обычным таймером приходится отдельно рассчитывать времена, задавать каждый интервал и следить за порядком этапов.

Photochem связывает расчёт и таймер в один сеанс. До старта показывает времена всех этапов, во время работы — оставшееся время и следующий шаг. Комплект химии сохраняется между сеансами, поэтому число уже обработанных плёнок не приходится считать заново перед каждой проявкой.

## Использование

Перед первой проявкой создайте комплект химии: выберите процесс и укажите дату приготовления. Следующие сеансы запускаются из этого же комплекта.

Сеанс проходит так:

1. Укажите количество плёнок в бачке. До запуска доступны рассчитанные времена всех этапов.
2. Нажмите «Старт», когда готовы начать этап. На экране появятся оставшееся время и следующий этап; перед окончанием прозвучит предупреждение.
3. После финального сигнала таймер перейдёт к подготовке следующего этапа. Сам сигнал закончится автоматически. Следующий этап начинается по нажатию «Старт».

Текущий этап и отсчёт также отображаются на экране блокировки через Live Activity.

## Расчёт и выполнение сеанса

Для этапов, зависящих от пробега, приложение берёт табличные времена для всех плёнок в бачке, усредняет их и округляет до пяти секунд. Этапы с фиксированным временем используют заданную длительность. Перед запуском проверяется, что новая проявка не превысит ёмкость комплекта.

Рассчитанные времена фиксируются при старте и сохраняются в истории. Обновление процессов не меняет уже начатую проявку.

Паузы у этапа нет. Сеанс можно прервать целиком; его статус и времена сохранятся, а плёнки будут учтены в пробеге химии.

## Учёт химии

В журнале сохраняются дата приготовления комплекта, пробег и история сеансов. По возрасту комплекта приложение предупреждает об истечении срока хранения; на время этапов возраст не влияет. Использованные комплекты можно архивировать.

## Разработка

Требования: macOS, Xcode с поддержкой Swift 6 и iOS SDK. Приложение работает на iPhone с iOS 18 и новее.

Откройте workspace из корня репозитория:

```sh
open Photochem/Photochem.xcworkspace
```

Выберите схему **Photochem** и симулятор iPhone. Для запуска на устройстве настройте подпись в **Signing & Capabilities**. Workspace подключает локальный пакет ядра и его тесты; отдельного Xcode-проекта для этого недостаточно.

### Устройство приложения

| Компонент | Ответственность |
|---|---|
| [Photochem](Photochem/Photochem/) | SwiftUI-экраны, выполнение сеанса, звуки, уведомления и хранение данных |
| [PhotochemCore](Photochem/PhotochemCore/) | Расчёт времени и валидация процессов; не зависит от SwiftUI и SwiftData |
| [PhotochemWidgets](Photochem/PhotochemWidgets/) | Отображение Live Activity |

Стек: Swift 6, SwiftUI, Observation, SwiftData, ActivityKit и WidgetKit. Архитектура — MVVM; зависимости собираются через Swinject, SwinjectAutoregistration и JustKitDI.

### Тесты

**Product → Test** в схеме **Photochem** запускает тесты приложения и ядра. Только тесты ядра:

```sh
swift test --package-path Photochem/PhotochemCore
```

Тесты написаны на Swift Testing. Для проверки стиля используется SwiftLint.
