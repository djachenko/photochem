# Photochem

Проявка фотоплёнки без бумажки: журнал комплектов химии, расчёт времён этапов с учётом пробега и усреднения для нескольких плёнок в бачке, таймер-поводырь по процессу.

- Приложение: [Photochem/](Photochem/) — Xcode-проект, iOS 18+, SwiftUI
- Канонический конфиг процессов: [config/processes.json](config/processes.json)
- Спецификация и документация — в памяти проекта: `_claude/docs/` (симлинк на `~/projects/_memory/photochem/`)

Соседний `../ConvenienTimer` — старый отдельный проект, лежит как референс, не трогать.
