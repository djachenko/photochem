# Photochem

Photochem — таймер для проявки плёнки на iPhone. Рассчитывает время этапов с учётом пробега химии и количества плёнок в бачке, ведёт по процессу и сохраняет историю проявок для каждого комплекта химии.

## Зачем отдельный таймер

Один комплект химии используется для нескольких проявок. По мере использования время некоторых этапов может меняться, поэтому перед очередной проявкой нужно учесть, сколько плёнок уже прошло через комплект и сколько будет в бачке сейчас. Приложение вычисляет пробег по истории сеансов и автоматически учитывает его при расчёте — вести отдельный счёт плёнок не нужно.

## Функции

- Расчёт времени всех этапов перед началом проявки по выбранному процессу, пробегу комплекта и количеству плёнок в бачке.
- Таймер с отображением текущего и следующего этапов. Каждый этап запускается вручную, после его завершения приложение переходит к подготовке следующего.
- Live Activity с текущим этапом и отсчётом на экране блокировки.
- Журнал комплектов химии: процесс, дата приготовления, пробег, предупреждение об истечении срока хранения и архив использованных комплектов.
- Контроль пробега: количество плёнок из предыдущих сеансов автоматически учитывается при расчёте новой проявки и проверке оставшейся ёмкости комплекта.
- История завершённых и прерванных сеансов с рассчитанными временами этапов.

## Расчёт времени

Пробег комплекта — общее количество плёнок во всех его сеансах. Новые плёнки получают следующие порядковые номера: например, после четырёх проявленных две плёнки в бачке будут пятой и шестой. Для каждого этапа приложение берёт времена этих плёнок из таблицы процесса, усредняет их и округляет результат до ближайших пяти секунд. Длительность фиксированных этапов не меняется.

Например, если для пятой плёнки задано 3:15, а для шестой — 3:30, обе пройдут этап вместе за 3:25: среднее 3:22,5 округляется до ближайших пяти секунд.

При старте сеанса приложение сохраняет рассчитанные времена. Обновление процессов не меняет их ни в текущем сеансе, ни в истории.

## Ограничения

- Начать сеанс нельзя, если количество плёнок превысит оставшуюся ёмкость комплекта.
- Поставить этап на паузу нельзя. Можно прервать весь сеанс, но его плёнки всё равно войдут в пробег химии.
- Возраст химии не влияет на расчёт времени. Дата приготовления используется только для предупреждения об истечении срока хранения.

## Стек и архитектура

- Swift 6, iOS 18+.
- SwiftUI и Observation — интерфейс и состояние экранов.
- SwiftData — хранение данных.
- ActivityKit и WidgetKit — Live Activity.
- Swinject, SwinjectAutoregistration и JustKittenDI — внедрение зависимостей.
- Swift Testing — тесты.
- SwiftLint — проверка стиля кода.

Архитектура — MVVM. Экраны, сервисы, расчётное ядро и ресурсы собраны в Swift-пакет с продуктами `PhotochemModule`, `PhotochemCore` и `PhotochemWidgetsUI`. Отдельная оболочка подключает модуль и показывает его корневой экран.

| Компонент | Ответственность |
|---|---|
| [PhotochemModule](PhotochemModule/) | SwiftUI-экраны, выполнение сеанса, звуки, уведомления и хранение данных |
| [PhotochemCore](PhotochemModule/Core/) | Расчёт времени и валидация процессов; не зависит от SwiftUI и SwiftData |
| [PhotochemWidgetsUI](PhotochemModule/Widgets/) | Отображение Live Activity |
| [PhotochemApp](PhotochemApp/) | Точка входа приложения, assets и тонкое расширение виджета |

## Разработка

Открывать `Photochem.xcworkspace`, схема `Photochem`. Корневой `Package.swift` описывает переиспользуемые targets; исходники оболочки находятся непосредственно в `PhotochemApp/`. Тесты приложения из `PhotochemModule/Tests/` запускаются вместе с тестами ядра через общий test plan.

Самостоятельные тесты ядра: `swift test --package-path PhotochemModule/Core`. Линтер запускается командой `swiftlint` из корня репозитория.

Канонические JSON процессов находятся в `PhotochemModule/Resources/Config/` и включаются в ресурсы пакета. Bundled-загрузка не требует индекса; для remote-доставки его генерирует `bash PhotochemModule/Scripts/generate_config_index.sh`. Общий каталог строк приложения и виджета — `PhotochemModule/Resources/Strings/Localizable.xcstrings`.
